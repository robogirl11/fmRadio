# My first FM radio!
Using Hackclub's Static as a guide for the pcb and schematic I worked on making an FM radio. Since this was my first time the guide was really helpful. I will be using the kit so I don't need to buy any parts. (thats why theres no BOM) I worked on this for around 4.5 hours. It is able to go to channels between 87.5-108.0. I will update this when I get it built with a photo. So far I have the photos of the pcb, schematic, & the 3d modeled pcb. I didn't make a case since I have an AM radio without a case and I like the look without the case so I didn't feel the need to make it. I think it also looks cooler that way.
